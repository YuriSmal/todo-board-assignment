# ToDo list test assignment

## The live preview of the application can be found here: https://yurismal.github.io/todo-board-assignment/

## To build the project locally:
1. Clone the repository:
``` 
git clone git@github.com:YuriSmal/todo-board-assignment.git
```
2. Navigate to the project root dir and install the packages:
```
npm i
```
3. Start the development server:
```
npm run dev
```
4. Open your browser and navigate to ` http://localhost:5173/todo-board-assignment
` to see the application in action (if port 5173 is already live, check the terminal to get the correct localhost url).
